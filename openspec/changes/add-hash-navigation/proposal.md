## Why

В настоящее время навигация между экранами расширения (перевод, результат, история, избранное, настройки, обратная связь, опции) управляется внутренним состоянием массива в `ExtensionApp.svelte`. Из-за этого не работают стандартные кнопки навигации браузера («Назад» / «Вперед», сочетание Alt+Left и боковые кнопки мыши), при перезагрузке страницы сбрасывается текущий экран, а также невозможны прямые ссылки на конкретные страницы. Внедрение маршрутизации на основе URL-хэша (`#/...`) решает эти проблемы без раздувания размера бандла.

## What Changes

- Добавлен легковесный реактивный модуль Hash-роутера (`src/lib/router.js`), синхронизирующий активный экран с `window.location.hash`.
- Поддержаны стандартные события навигации браузера (`hashchange`, `popstate`, а также нажатие боковой кнопки мыши «Назад»).
- Локальное состояние `routeStack` в `ExtensionApp.svelte` заменено на реактивный стор роутера.
- Кнопки возврата в UI (`←`) обновлены для перехода по истории браузера с безопасным fallback на начальный экран.

## Capabilities

### New Capabilities
- `navigation`: Маршрутизация на основе URL-хэша, навигация по истории и обработка событий кнопок «Назад» для экранов расширения.

### Modified Capabilities
<!-- None -->

## Impact

- `src/lib/router.js`: Новый модуль стора роутера и вспомогательных функций навигации.
- `src/lib/ExtensionApp.svelte`: Рефакторинг для использования стора роутера вместо локальных переменных `route` и `routeStack`.
- `src/lib/components/PageFrame.svelte` и страницы: Вызовы навигации переведены на методы роутера.
- Внешние runtime-зависимости не добавляются.
