## Purpose

Предоставляет маршрутизацию на основе URL-хэша и навигацию по истории браузера для всех экранов расширения.

## ADDED Requirements

### Requirement: Hash-based view routing
Система ДОЛЖНА синхронизировать активный экран приложения с URL-хэшем браузера (`#/translate`, `#/result`, `#/history`, `#/favorites`, `#/settings`, `#/feedback`, `#/options`).

#### Scenario: Переход на экран
- **WHEN** пользователь или приложение инициирует переход на целевой экран (например, `settings`)
- **THEN** URL-хэш обновляется на `#/settings` и отображается экран настроек

#### Scenario: Инициализация экрана по умолчанию
- **WHEN** приложение загружается без хэша или с неизвестным хэшем
- **THEN** приложение отображает экран по умолчанию для текущего контекста (`translate` для всплывающего окна, `options` для страницы опций) и нормализует хэш

### Requirement: Browser history and back navigation
Система ДОЛЖНА поддерживать стандартную навигацию по истории браузера, включая кнопки «Назад» / «Вперед» браузера, горячие клавиши и боковую кнопку мыши «Назад».

#### Scenario: Навигация кнопкой «Назад» браузера
- **WHEN** пользователь нажимает кнопку «Назад» в браузере, боковую кнопку мыши или сочетание клавиш Alt+Left
- **THEN** система переключает текущий экран на предыдущий маршрут из истории браузера

#### Scenario: Нажатие кнопки «Назад» в UI при наличии истории
- **WHEN** пользователь нажимает кнопку «←» в интерфейсе и в истории есть предыдущие экраны
- **THEN** система выполняет возврат к предыдущей записи в истории браузера

#### Scenario: Нажатие кнопки «Назад» в UI без истории переходов
- **WHEN** пользователь нажимает кнопку «←» в интерфейсе на вторичном экране при отсутствии предыдущей истории
- **THEN** система переходит на начальный экран по умолчанию для текущего контекста
